# @threeify/cli

> Manage 3D assets from your terminal and CI pipelines.

Upload, download, convert, and version assets on [Threeify](https://threeify.com), or keep your application's asset selections in Git. Requires Node.js 22.12 or newer.

## Installation

```sh
npm install -g @threeify/cli
```

## Usage

```sh
threeify --version
threeify auth login
threeify assets list --org my-org --project my-project
```

Run `threeify --help` for help in your terminal.

## Documentation

Read the [CLI guide](https://docs.landofassets.com/cli-guide), [command reference](https://docs.landofassets.com/cli), and [asset manager guide](https://docs.landofassets.com/asset-manager) for authentication, configuration, asset selections, and automation.
